## 安装和恢复

实际文件和已安装状态见 manifest.json。新 supervisor 为 `x2v_product_boot_20261017a.sh`，旧版 `x2v_product_boot_20261015c.sh` 仍保留。所有变更使用新文件名，不覆盖旧版启动脚本。

如需回退，先停止录制并退出视频，再停新 supervisor，将新启动脚本改名为 `.disabled`，恢复 /system 只读，启动旧 supervisor。保留素材与隐藏元数据，不能删除 DCIM 或整棵 X2V_RAW。

断电时尚未发布的片段保留在 staging；此版本不自动扫描修复断电未完成的 MOV。
