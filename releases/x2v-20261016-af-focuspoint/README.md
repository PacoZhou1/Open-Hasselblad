# X2V 2026-10-16 持续 AF 对焦点修复

适用于已安装 X2V 的 X2D II / 原厂 1.3.16.2。这是持久化扩展增量包，不是原厂 CIM 刷机包，依赖现有自动启动模块、录制和播放程序。

基于恢复点 c67f3c8d，继承持续 AF、24/25/30fps 设置、录制及回放功能。修复视频连续 AF 时触屏选点后无法再移动、原厂会话状态拦截摇杆和回中请求的问题。

此次更新四个 QML 文件；三个已有界面组件和一个新增的原厂模型子类。保持原厂类型、对焦点边界/裁切算法和真实会话状态，只允许视频连续 AF 状态下移动焦点。原有录制/传感器/ISP/对焦二进制均未重编译或改变。QML 由相机上的 Qt 加载编译。

验证：主机 Qt 行为测试通过；实机输入触屏 A→B→A，原生 focus_point 精确返回 A，期间 AF 持续 RunningCont。用户随后实机操作并确认“成功了 我试了试”。自动注入 event0 方向键没有使焦点移动，因此自动化结果不能作为五维摇杆验收；本项以用户实机确认记录为依据。

四个文件已放入 /blackbox/x2v-native-20261011/gui 持久目录并由既有开机自动加载链使用，当前已运行。此次没有强制重启相机；新文件的重启后物理验证尚未再次执行。

30fps 原有掉帧限制和间歇性近距离精度问题不在本次修复范围。此前重要恢复点及其安装包保持不变。安装证据见 installation.json。
