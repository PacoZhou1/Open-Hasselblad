# X2V 20261021a：24/25fps 异常格点修复

本增量版本已永久安装到这台 X2D II（原厂固件1.3.16.2），基于已装的 x2v-20261017-flat-prr / 6648b237。当前相机选择 ProRes RAW /25fps，处于视频待机，没有活动错误。

## 改动

24与25fps 均只重建绝对 x 为奇数、绝对 y mod6=1 的异常 Bayer 样点，约占1/12；保留同一行原本正常的绿色采样。现有裁切坐标对应 x奇、y mod6=5。修复只使用当前帧的同色邻点，不识别场景、不拟合测试卡、不累积历史参数。

正式库没有同帧诊断写盘入口。保持各档原有读出/AF、GUI、曝光、白平衡、编码器和保存路径。30fps仍使用原版库；DNG路径不受本改动影响。

新启动脚本 x2v_product_boot_20261021a.sh；新会话脚本 x2v_video_session_20261021a.sh；新库 libx2v_classonly24_20261021a.so / libx2v_classonly25_20261021a.so。旧稳定启动脚本和旧录制库保留。

## 已验证与限制

- 24fps 的同帧 ARM64/NEON 输出与主机C重放逐值相同，异常类以外全部保留，异常类插值与旧版相同。
- 正式版25fps第二段：103帧，dropped=0，lost=0，error=0。源时间间隔102/4.080083 ≈24.9995fps；MOV声明25/1、4.12秒、103帧。
- 正式版24fps第二段：116帧，dropped=0，lost=0，error=0。源时间间隔115/4.791766 ≈23.9995fps。
- 第一段25fps有2帧掉帧（首个1.4秒采样前已经发生，此后计数不增加）；第一段24fps有3帧掉帧（2帧在首个采样前、另1帧在最后一段/停止窗口）。更早安装首轮分别有5/3帧。不能宣称首次启动或长录制绝不掉帧。实际拍摄前可先短录一次，让编码器和缓冲完成首次工作。
- 两档均正常停止、发布MOV并恢复待机。25fps样片已取回电脑解析及检查，未见原细密周期横纹复发；高频伪色/摩尔纹仍有残留，不宣称所有场景已经验收。
- 安装4个文件读回一致，/system只读；原有Weston模块重新启动后实际自动选择新启动脚本，恢复25fps及界面。没有做整机关机冷启动验证，也未重新进行户外、长录或本轮机身按键的完整验收。

## 防休眠

电脑联机保活继续开启，ensure 已修复“电脑续租worker死亡时不重启”的问题。断开电脑后仍按开发保活租约原有规则，在租约过期后恢复正常待机设置，不永久关闭原厂休眠或温控。

## 分区空间及回退

由于/system可分配空间约1MB，将两个未使用且未被启动配置引用的旧诊断库 cd_observer / range_observer 备份至 /blackbox/x2v-native-20261011/classonly-release-20261021/archive 后从/system移出。没有删除旧稳定录制库、照片或视频。备份SHA见安装证据。

如需回退：先停止录制并退出视频，停止新supervisor，将 /system/etc/x2v/x2v_product_boot_20261021a.sh 改名为 .sh.disabled，恢复/system只读，再启动 /system/etc/x2v/x2v_product_boot_20261017a.sh。不要改写旧脚本或旧库。

apply.sh 是针对已安装20261017-flat-prr基线的增量安装器，不是原厂可刷写升级包。需退出录制/视频并停止当前supervisor后由工厂root通道执行；已有目的文件只接受相同SHA，不覆盖不同内容。
